### ✅ B-06【后端·高危·已修复】模型权重上传路径穿越 + 远程代码执行

- **修复代码**：
```python
# 顶部新增
import re
from werkzeug.utils import secure_filename

# 接口内
if not re.match(r'^[\w.\-]+$', version_name):
    return jsonify({'code': 400, 'message': '版本号包含非法字符'}), 400
# ...
filename = f"{secure_filename(version_name)}_{secure_filename(file.filename)}"
```
- **验收**：`version_name="../../../etc/passwd"` 返回 400；落盘文件名被 `secure_filename` 规整。

### ✅ F-08【前端·高危·已修复】聊天/报告 `v-html` 存储型 XSS
- **位置**：`chat/ChatPage.vue`、`patient/ChatPage.vue`、`approval/ApprovalPage.vue`、`patient/ReportListPage.vue`、`batch/BatchDiagnosePage.vue`
- **现象**：`formatMessage(msg.content)` 与 `formatReport(...)` 把**用户/模型内容**经 `v-html` 渲染，仅做 `\n→<br>`、markdown 加粗，未转义原始 HTML；攻击者或提示注入可在聊天气泡执行脚本。
- **风险**：🔴 存储/反射型 XSS（CWE-79）
- **根因**：先渲染后未转义，或直接 `replace` 注入 `<br>` 透传原文字符串。
- **修复范式**：
  - 聊天消息：先 `escapeHtml` 再应用 markdown：
```ts
import { escapeHtml } from '@/utils/xss'
function formatMessage(text: string) {
  const escaped = escapeHtml(text || '')
  return escaped
    .replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>')
    .replace(/\n/g, '<br>')
    .replace(/^(#{1,3})\s(.+)$/gm, (_m, _h, t) => `<strong>${t}</strong>`)
}
```
  - 报告文本：`sanitizeHtml(content.replace(/\n/g, '<br>'))`（白名单 b/i/u/em/strong/p/br/ul/ol/li，剥离 script/on* 事件/javascript:）。
  - 批量报告：章节标题与正文均 `escapeHtml(...)` 后再做关键词高亮。
- **验收**：消息内容输入 `<img src=x onerror=alert(1)>` 仅显示为纯文本；`vue-tsc` 对 5 个文件 0 错误。

### 🔴 待实施（高）
- **B-01~B-05 鉴权缺失/可绕过**：部分 API 蓝图未统一挂载 `@require_auth`，存在未鉴权即可读患者/报告的端点。→ 见模块五统一装饰器方案。

## 三、模块二 · 逻辑优化（Logic Optimization）

### ✅ S-01【后端·已修复】模型单例竞态
- **位置**：`backend/services/ai_service.py`
- **现象**：并发首调可能重复 `load_model`，双重加载占满内存并引发状态错乱。
- **根因**：无初始化锁。
- **修复代码**：
```python
_model_lock = threading.Lock()
def load_model():
    if is_model_loaded():
        return True
    with _model_lock:
        if is_model_loaded():
            return True
        # ...实际加载
```
- **验收**：压测并发首调只加载一次。

def require_auth(fn):

        token = request.headers.get('Authorization', '').removeprefix('Bearer ')

def require_role(*roles):

            return fn(*a, **k)
        return wrapper
    return deco
